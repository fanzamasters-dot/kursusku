# Refleksi Pertemuan 7

Perbedaan yang paling terasa antara PHP biasa dan Laravel adalah pembagian tugasnya. Di Laravel, alamat URL ada di routes/web.php, logika ada di controller, dan tampilan ada di Blade, sedangkan di prototype PHP biasa semuanya bercampur dalam satu file. Bagian yang paling mudah menurut saya adalah View atau Blade, karena {{ }} dan @foreach mirip dengan PHP yang sudah dipelajari. Bagian yang paling membingungkan adalah menghubungkan route ke controller dan mengirim data memakai compact(). Error yang saya temui adalah "Could not open input file: artisan" saat menjalankan php artisan. Saya membuktikan penyebabnya dengan melihat posisi terminal di C:\laragon\www, padahal file artisan ada di C:\laragon\www\kursusku, dan setelah pindah dengan cd kursusku perintahnya berjalan.
